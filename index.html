The pipeline behind it

  1. 01

    Produce

    Explore the app, file the cases, generate traceable specs.

    claude-qa-tms ↗
  2. 02

    Select

    Run only the specs a change can affect; escalate when narrowing can't be justified.

    playwright-test-selector ↗
  3. 03

    Trust

    Score flakiness on evidence. Quarantine with an expiry date, never forever.

    flake-radar ↗
  4. 04

    Measure

    Known bugs as tracked state; an agent that repairs one selector and proves it.

    self-healing-e2e ↗
  5. 05

    Explain

    Every automated decision lands where a person can argue with it. That is what the gate above does.
